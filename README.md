# bo-fo.github.io

Project page of **BO-FO** — *Bayesian Optimization of a Fourth-Order Extended State Observer With Pole Relocation for Robot Manipulators*
(Hwarang Kim, Sesun You; manuscript under review, IEEE Transactions on Industrial Electronics, 2026).

Live page: https://bo-fo.github.io

Static site, no build step (GitHub Pages serves the `main` branch root):

- `index.html`, `styles.css`, `site.js` — the page; `site.js` only drives the featured-video picker.
- `assets/` — figures (PNG) and poster frames (`assets/posters/`).
- `videos/` — the narrated supplementary video (`supp_video.mp4`, 3:11), its six slide segments with narration (`s1_overview` … `s6_summary`), and `videos/loops/` — one looping clip per hardware setting (y, z and end-on x lines, one cycle, measured deviation drawn ×100; rendered by `video/make_page_loops.py` of the paper repository).
